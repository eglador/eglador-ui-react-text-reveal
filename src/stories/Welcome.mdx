Letter-by-letter text reveal animations for React — pure CSS, zero runtime
dependencies, Tailwind v4 friendly, SSR-safe, respects `prefers-reduced-motion`.

---

## Installation

```bash
npm install eglador-ui-react-text-reveal
```

## Quick Start

```tsx
import { TextReveal } from "eglador-ui-react-text-reveal";

<TextReveal variant="cinematic-blur">ARVENIS</TextReveal>
```

## Features

- **Zero runtime dependencies** — `clsx` and `tailwind-merge` are pre-bundled
- **Pure CSS animations** — no framer-motion, no animation engine
- **SSR-safe** — keyframes injected on client mount
- **Accessible** — wraps text with `role="text"` and `aria-label`; each
  letter is `aria-hidden`. Respects `prefers-reduced-motion` automatically
- **Tree-shakeable** — `sideEffects: false`, ESM + CJS dual builds
- **TypeScript-first** — typed variant union, fully typed props
