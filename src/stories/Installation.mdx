# Installation

Package installation, peer dependencies, and Tailwind v4 integration.

---

## 1. Install the package

```bash
npm install eglador-ui-react-text-reveal
```

```bash
yarn add eglador-ui-react-text-reveal
```

```bash
pnpm add eglador-ui-react-text-reveal
```

---

## 3. Tailwind v4 `@source` (optional)

`TextReveal` does not rely on Tailwind utility classes for its animations
(everything is injected as plain CSS). You only need an `@source` entry if
you compose Tailwind utilities around it from inside the package:

```css
@import "tailwindcss";
@source "../node_modules/eglador-ui-react-text-reveal";
```

For typical usage where you style the wrapper via your own Tailwind classes
this step is not required.

---

## 4. Server components note (Next.js)

`TextReveal` is marked `"use client"` because it injects styles on mount.
Import it from a file that already carries the `"use client"` directive,
or use it inside a client component.
